# Présentation du Film

Ce site présente un film avec son titre, affiche, synopsis, acteurs principaux et une bande-annonce.

## Structure
- `index.html` : page principale
- `style.css` : styles modernes et responsive
- `script.js` : interactions JavaScript (optionnel)

## Personnalisation
Remplacez les informations par celles de votre film (titre, synopsis, acteurs, affiche, bande-annonce).

## Aperçu
Ouvrez `index.html` dans votre navigateur.
